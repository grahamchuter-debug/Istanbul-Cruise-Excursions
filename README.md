# Istanbul Cruise Excursions

Independent Istanbul cruise planning site for passengers calling at Galataport.

**Domain:** https://istanbulcruiseexcursions.com

## Commands

```bash
npm install
npm run dev          # local development
npm run build        # static export to out/
npm run check-links  # internal link validation
npm run seo-qa       # SEO QA (run after build)
npm run pages:deploy # Cloudflare Pages deploy
```

## Stack

Next.js 16 (static export), React 19, Tailwind CSS 4, Cloudflare Pages.

Core identity: **Two continents. One unforgettable cruise port.**
